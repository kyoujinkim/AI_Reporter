# AI_Reporter

공시·재무자료·뉴스를 모아 기업 분석 보고서를 작성하는 Python 기반 AI 리서치 워크플로입니다. 분석 모듈을 연결하고 사람이 내용을 검토·수정하는 과정과 Markdown 보고서의 PowerPoint 변환을 포함합니다.

## 워크플로

```text
기업 코드·산업 설명
  → DART 기업정보·사업보고서·실적 자료
  → 사업·재무·실적·뉴스 분석
  → 시나리오와 보고서 초안
  → 사람의 검토·수정
  → Markdown·텍스트·차트·PowerPoint
```

| 경로 | 역할 |
|---|---|
| `run.py` | CLI 진입점과 분석 실행 순서 |
| `src/ai_reporter.py` | 보고서·시나리오·차트 구성 |
| `src/tools/` | 사업·재무·실적·뉴스·컨센서스 등의 분석 도구 |
| `src/tools/human_interrupt.py` | 사람의 검토·수정 단계 |
| `src/md_to_pptx_converter.py` | Markdown → PowerPoint 변환 |
| `data/config/` | 도메인 설정·보고서 템플릿 |

모듈이 존재한다는 사실과 기본 CLI에서 해당 모듈을 모두 실행한다는 것은 다릅니다. 실제 실행 순서는 `run.py`를 기준으로 합니다.

## 현재 상태와 사전 준비

연구용 워크플로로, 외부 서비스 인증·재무 워크북·템플릿·로컬 경로 준비가 필요합니다. 전체 실행을 검증한 배포 패키지는 아닙니다.

특히 다음을 먼저 정리해야 합니다.

- `run.py`와 여러 모듈이 참조하는 `D:/config.ini` 경로를 사용자 환경에 맞게 통일합니다.
- `src/tools/agents.py`, `pdf_parser.py`, `summarizer.py`의 `httpx.Client(verify=False)`를 제거하고 인증서 검증을 활성화합니다. 기관 인증서가 필요하면 신뢰할 CA를 설정합니다.
- `requirements.txt`에 빠진 직접 import 의존성·Excel 엔진·선택 기능용 도구를 확인하고 별도 환경에서 설치를 검증합니다.
- 사용할 모델은 소스의 모델 설정과 서비스 접근 권한을 함께 확인합니다.

## 설치

```bash
python -m venv .venv
# 가상환경 활성화 후
python -m pip install -r requirements.txt
```

PDF 이미지 변환 기능은 `pdf2image` 외에 시스템 PDF 변환 도구가 필요할 수 있습니다. 브라우저 기능은 브라우저 설치와 경로 설정, 차트는 한글 폰트 준비가 필요할 수 있습니다. 사용하는 기능에 맞게 설정하세요.

## 인증과 입력

현재 코드가 읽는 INI의 최소 구조는 아래와 같습니다. 실제 값은 비공개 파일에만 저장합니다.

```ini
[dart]
API_KEY =

[openai]
API_KEY =

[tavily]
API_KEY_NH =
```

키 이름은 현재 코드와 맞춘 것입니다. 예제 파일을 만드는 것만으로 코드의 설정 경로가 바뀌지는 않습니다.

재무 분석 모듈은 기업별 작업 디렉터리의 `IS.xlsx`를 읽습니다. 소스에는 `sales`, `op`, `income`, `costsales`, `costincome`, `netdebt` 시트와 `header=9`, `index_col=1` 형식이 사용됩니다. `data/IS.xlsx` 한 파일만 둔다고 기업별 경로 준비가 자동으로 완료되는 것은 아니므로 `src/tools/financial_analyst.py`의 작업 디렉터리를 확인하세요.

PowerPoint 변환에는 `data/config/template.pptx`가 필요합니다. 템플릿을 교체할 때는 변환기가 사용하는 레이아웃·자리표시자와 호환되는지 확인해야 합니다.

## 실행

설정 경로·인증·입력·템플릿·인증서 문제를 정리한 후, 저장소 루트에서 실행합니다.

```bash
python run.py --code 005930 --industry "반도체"
```

기업 코드와 산업 설명은 분석 대상에 맞게 바꿉니다. 실행 중 사람의 입력이 필요한 단계가 있을 수 있으며 외부 API 사용료가 발생할 수 있습니다. 예시는 실행 형식이며 해당 기업에 대한 결과를 검증했다는 의미는 아닙니다.

## 결과와 검토

기업별 `output/A<기업코드>/` 등을 중심으로 Markdown, 차트, 변환 파일을 저장합니다. 소스 모듈마다 작업 경로가 다를 수 있으므로 실행 전에 출력 디렉터리를 확인하세요. 과거 결과 파일을 재사용하는 분기도 있어, 재실행 시 기준일과 기존 파일을 함께 관리해야 합니다.

LLM이 만든 실적 설명·시나리오·차트 수치는 공시 원문과 대조해야 합니다. 컨센서스·실적·추정치의 기준일과 단위를 맞추고, 출처가 없는 수치나 추론을 확정 사실로 사용하지 마세요.

## 데이터와 라이선스

보고서 원문·재무 워크북·뉴스·회사 템플릿은 각각의 배포·외부 전송 권한을 확인해야 합니다. 외부 모델에 보낼 수 있는 입력만 사용하세요. 코드의 `LICENSE`가 데이터·브랜드·템플릿 권리까지 포함한다고 가정해서는 안 됩니다.
