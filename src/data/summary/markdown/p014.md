# p014 요약

## 1) 핵심 요약
- 2023년 케이카의 유효시장 점유율은 12.3%로 증가, 2024년에는 12.7%로 예상됨.
- 전체 시장은 2023년 2,553,785대, 전년 대비 1.0% 증가.
- 유효시장은 1,245,405대로, 전년 대비 3.4% 감소.
- 2025년 상반기 유효시장 규모는 614,230대로, 전년 대비 4.3% 감소 예상.

## 3) 그래프/도표 해석
- 케이카의 유효시장 점유율은 지속적으로 증가하는 추세이며, 2023년과 2024년 모두 상승세를 보임.
- 전체 시장은 2023년에 소폭 증가했으나, 유효시장은 감소세를 보이며 리스크 요소로 작용할 수 있음.

## 4) 용어 및 주석
- 유효시장: 사업자 거래 매도 + 상사 이전 + 알선 거래
- 전체시장: 총 이전 등록 대수 - (매입 이전 등록 대수 + 기타)
- 출처: 카이즈유 데이터 연구소 (국토교통부 자동차 등록 데이터 자료 기준), 자사 데이터
- 단위: 대 (대수 기준)
