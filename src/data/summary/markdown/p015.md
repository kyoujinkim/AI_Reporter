# p015 요약

## 1) 핵심 요약
- 2025년 2분기 케이카 판매 대수는 38,468대로, 전년 동기 대비 1.4% 감소, 전 분기 대비 2.4% 감소.
- 이커머스 판매는 지속적으로 증가하는 추세를 보이고 있으며, 오프라인 판매는 다소 감소.
- 2024년 1분기 이커머스 판매 대수는 17,119대, 오프라인 판매 대수는 9,481대.
