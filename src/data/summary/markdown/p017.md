# p017 요약

## 1) 핵심 요약
- 2025년 2분기 매출은 608,869백만원으로, 전분기 대비 0.7% 증가.
- 매출총이익은 62,284백만원으로, 전분기 대비 5.4% 감소.
- 영업이익은 18,121백만원으로, 전분기 대비 15.6% 감소.
- 당기순이익은 12,012백만원으로, 전분기 대비 16.8% 감소.
- 전체적으로 수익성 지표가 하락세를 보임.

## 3) 그래프/도표 해석
- 매출은 소폭 증가했으나, 매출총이익과 영업이익은 모두 감소하여 수익성이 악화됨.
- 특히, 영업이익과 EBITDA의 감소폭이 커 리스크가 증가하고 있음을 나타냄.

- EBITDA: 이자, 세금, 감가상각비 차감 전 이익
