# p022 요약

## 1) 핵심 요약
- 렌터카 매출 182억원, 전년 대비 12.3% 증가, 전 분기 대비 10.2% 증가.
- 대여료 매출 112억원, 렌터카 매각 매출 70억원.
- 렌터카 운영 대수는 5,310대.
- 기타 매출 23억원, 전년 대비 8.2% 증가, 전 분기 대비 5.1% 감소.
- 기타 매출 항목에는 홈서비스 탁송비, 금융 프로모션 수입 등이 포함됨.

## 3) 그래프/도표 해석

- 기타 매출은 전년 대비 증가했으나, 최근 분기에서는 감소세를 보임.
